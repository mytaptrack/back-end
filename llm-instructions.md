In the back-end project, create a script that exports data by license. For each license, a folder should be created. In each folder for each student a folder should be created. In each student's folder all of their tracked data should be exported simular to how the data is exported in the user interface. The student's configuration should also be exported to a config.json file.

The folder structure for this should be:
- license/
    - student name/
        - data.csv
        - config.json
