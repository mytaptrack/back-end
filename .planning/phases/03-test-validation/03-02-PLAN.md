    ```
    "test:aws": "USE_LOCAL=false && node src/aws-test-setup.js && USE_LOCAL=false jest"
    ```

    USE_LOCAL as a process environment variable for child processes. The `node`

    ```
    "test:aws": "USE_LOCAL=false node src/aws-test-setup.js && USE_LOCAL=false jest"
    ```

    dependencies, devDependencies, jest config).

    Also add a diagnostic log to aws-test-setup.js so it confirms USE_LOCAL is
    received correctly. After the line `process.env.USE_LOCAL = 'false';`, add:
